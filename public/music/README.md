# Background Music Instructions for Elora Moments

This folder contains background instrumental music for the digital birthday invitations.

### Default Music Track:
`public/music/krishna-flute-melody.mp3`

### Requirements:
- Format: MP3 or AAC (96-128kbps recommended for fast mobile loading)
- Style: Gentle Bamboo Flute (Bansuri), Veena, or soft Indian devotional classical melody (Raag Bhupali / Mohanam).
- Licensing: Must be original composition or royalty-free licensed track.

### Automatic Built-In Web Audio Synthesizer:
If no MP3 file is present in this directory, the application automatically activates its built-in Web Audio API synthesizer which generates soothing Krishna flute harmonics in real-time without requiring any external audio download!
